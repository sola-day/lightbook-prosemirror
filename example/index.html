lightbook-prosemirror

Shared ProseMirror editor core for Lightbook — Outline-style rich blocks and tables, Markdown import/export, Google-Docs-style comments & suggesting, and Yjs realtime collaboration. Built fresh for this package, not copied from Outline.

Realtime collaboration (two editors, one Yjs doc)

Type in either pane — both stay in sync through the same in-memory Y.Doc via y-prosemirror, with live remote cursors.

Comments & suggestion mode

Select text in Editor A, then use the toolbar to add a comment or toggle "Suggesting" mode (deletions show struck-through, insertions underlined, until accepted/rejected).
